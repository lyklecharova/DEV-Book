# DEV-Book

Run routine project commands directly when they are within the requested task. This includes inspecting files, checking Git status, and running builds, lint checks, and tests. Use automatic approval when the environment offers it and follow any approval requirements imposed by the environment.

Before committing or pushing project changes, show the user the changes and wait for their approval. Once approved, proceed with the agreed commit and push without asking again unless the changes or target branch materially change.
